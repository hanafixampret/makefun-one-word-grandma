One word, and nothing else: the single word a grandma would text about AI.

This entry is one word: **doohickey** — what she calls the clever little machine on the counter, said with a smile and zero idea how it works. The program validates the word (letters only, 1–30 characters) and writes it to `entry.txt`.

## Run it

```sh
node main.ts
```
